## Major updates

This rolling log records meaningful, shipped improvements to the attendance workflow. It is intentionally curated rather than a list of every code change.

### August 2026

- Added attendance start dates so required meetings before a member joined do not lower their attendance rate.
- Added per-member excuses, clearly separating excused absences from attendance corrections.
- Added open check-in visibility to help mentors follow up on sessions that still need checkout review.
- Improved kiosk Wi-Fi setup and on-screen connection guidance for everyday recovery.
- Added Discord calendar synchronization for scheduled meetings, with later syncs updating the same calendar event.

### Earlier 2026

- Added mentor-ready scheduled-meeting summaries, absence drilldowns, roster attendance, and export ranges.
- Added auditable attendance corrections and an admin review path for Discord absence contests.
- Added kiosk health visibility and safe remote recovery actions for authorized dashboard users.
